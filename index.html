Board & Card Games

Companions, trackers and simulators I've built for games I actually play — each one a self-contained web app you can open and use right now. Every project lives in its own repository; the links below go straight to the live version.

Secret Hitler Companion

A table companion for Secret Hitler. Randomizes seating, tracks the boards and piles, and runs a live hypergeometric model of what each government's draw actually was — including what changes if a President lied.
